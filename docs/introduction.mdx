The Agent Chat API lets you start and follow **long-running, tool-using agent conversations** and run the three Magica media tools (`crop_image`, `gpt_image_2`, `merge_videos`) directly.

## Model

- A **chat** holds **messages**. Sending a message starts exactly one **run**.
- A run is durable: it survives client disconnects and reloads. Its state is always readable from `GET /runs/{runId}`.
- Runs may pause at a **waitpoint** (approval, options, plan, credit) that a human completes.
- Every request and response is validated against a runtime contract. Errors share one envelope (see [Errors](/errors)).

## Base URL

```
https://<your-deployment>/api/v1
```

## Quick start

Create an [API key](/api-keys) once, then start a conversation turn with a single call:

```bash
curl -X POST "$BASE/api/v1/completions" \
  -H "Authorization: Bearer ak_live_..." \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{"message":"Generate a poster of a lighthouse at dawn, then crop it to a square"}'
```

The response is `202 Accepted` with the `chatId` (a new chat unless you passed one), the `runId` and a `statusUrl`. Poll it, subscribe to the run's realtime channel, or register a [webhook](/webhooks). Pass `attachmentUrls` (public https URLs) to give the agent images or videos to work on, and `chatId` to continue an existing conversation. Media tools can also be called directly as [standalone tool runs](/tools).
